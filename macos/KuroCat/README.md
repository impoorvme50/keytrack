# KuroCat renderer

The Swift sources in this directory are from
[KuroCat](https://github.com/chanke17/KuroCat/tree/ec74619715e91976badc895fff93c60f386a60e7)
at commit `ec74619715e91976badc895fff93c60f386a60e7`, copyright chanke17, under
the accompanying MIT license.

Keytrack uses the upstream renderer, keyboard layout, built-in coats, and
animation physics. The local changes in `CatPhysics.swift` supply animation
frames from the Keytrack desktop pet and select built-in artwork. The
standalone app and its input engine are outside this integration.
