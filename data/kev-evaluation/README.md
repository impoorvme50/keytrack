# 中文 Kev 五候选评测数据

这是一组原创公开的日常与工作场景，不含用户输入历史、真实客户、邮件、输入采集内容或外部训练语料。场景、上下文、可接受完整答案和本项目工具按 `LICENSE.txt` 的 MIT 许可提供。

两份数据在请求模型前冻结：每份 60 条，日常／工作各 30 条；完整词 24、整句 18、歧义 12、拒绝 6。清单记录 SHA-256、分类数量、许可及来源。歧义样例允许多个自然解释，不能只承认一个人为答案。

- `evaluation-v1.json` 是人工五候选排序诊断集，原首项不代表 Rime 实际排名；部分坏候选有意保留。
- `evaluation-v2.json` 使用真实 librime 和已部署的公共 `rime_ice.table.bin` / `rime_ice.prism.bin` 在隔离环境采集前 5。上下文与答案沿用原创场景；拒绝部分使用采集脚本中预先固定的错拼音场景。它不代表个人调频及日常方案的所有过滤器。
- `evaluation-v2.manifest.json` 保存公共二进制、librime 与隔离方案的哈希，不分发二进制词典，也不变更第三方库或源词典的许可。快照中的词条是输入法产生的短词／句子数据。
- `capture_public_rime.py` 可以重新采集到新文件，拒绝覆盖既有冻结文件。它只复制上述两个公共二进制，临时 HOME、新方案、关闭用户词典、不加载 Lua／logger、不提交文本，结束后删除临时目录。

“完整词／整句”指本样例期待的完整输入单位。候选池可以含前缀，前缀不会按完整答案记为正确。原首项不好但目标根本不在前 5 时，Kev 的五选一不能救回它。拒绝样例测保留原序，不把“猜出新词”列为能力。

这 60 条是小型便利样例，不代表用户日常输入准确率，也不能用来训练模型或边测边调阈值。后续变化需要另建版本和独立未见样例，保留本轮冻结文件。使用方式、指标定义和实测结果见 `../../docs/kev-evaluation.md`。
