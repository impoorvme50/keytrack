# Keytrack 输入控制台

参考 AIME 的设置分区和即时预览，给现有鼠须管 + Keytrack 增加本机窗口。桌面窗口使用 SwiftUI 原生控件，统计和配置沿用本项目已验证的 Python 实现，通过私有进程管道交换 JSON。桌面版没有 WebKit、网页资源或 HTTP 服务；输入法仍由鼠须管绘制候选、处理按键。

## 打开

独立安装包为 `dist/Keytrack-0.4.1-apple-silicon.dmg`，适用于 Apple 芯片 Mac、macOS 26 及以上。打开磁盘镜像，将 `Keytrack.app` 拖入 `Applications`，从「应用程序」打开后点击「完成本机安装」→「备份并安装」。也支持个人的 `~/Applications` 目录。在磁盘镜像或源码目录直接打开时会提示先移动应用，避免后台服务绑定到临时位置。

应用包含 SwiftUI 界面、内置 Python 运行组件、PyObjC 和本项目的输入法接入脚本，不需要安装 Python 或 Homebrew，也不依赖项目位置和 `.venv`。采集继续使用已有的鼠须管；可选 AI 使用已有本机 Kev 模型服务，模型权重和模型服务没有放进安装包。首次安装不会改变 AI 开关或模型服务配置。

完成本机安装前，自动备份控制台配置、全部 Rime `*.custom.yaml`、采集 Lua 和原采集 LaunchAgent。安装备份在 `~/.keytrack/console/backups/<备份编号>-installation`；控制台的恢复按钮只恢复控制台管理的设置，不回退后台服务。安装后采集 LaunchAgent 和现有 Kev 候选桥接都使用应用内程序。历史和设置保存在个人目录；退出窗口关闭自己的桥接进程，后台采集仍可继续。

此版本使用本机临时签名，未进行 Apple Developer ID 签名和公证。开发构建运行 `./scripts/build-console.sh`，生成磁盘镜像运行 `./scripts/package-console.sh`。构建机需要项目虚拟环境、Xcode 和 `requirements-build.txt` 中的依赖；这些仅是开发依赖。原有 `kbd ui` 仍可用于打开项目里的构建结果。

另保留可选浏览器版 `kbd console`，不参与桌面应用运行。原生界面验收用 `open dist/Keytrack.app --args --demo`，需先退出已有窗口。测试配置和自造数据完全独立，不修改实际 Rime 配置。

## 已有功能

- 输入看板：每日上屏字数、活跃分钟、按活跃分钟计算的输入速度、退格占比、应用分布、两周趋势、91 天日历、小时分布、键盘热力图和按标准指法估算的手指负载。
- 当天原文默认折叠，只有主动展开才查询，最多显示最近 500 个片段。统计库以只读方式打开，窗口不执行补录，也不写历史库。内容统计仅覆盖鼠须管采集的上屏，不代表所有应用里的全部输入。
- 常用语支持分类、搜索、复制、编辑、多行内容，2–20 位小写字母编码，避开 v/u 开头。保存后作为独立 Lua 翻译器接入雾凇拼音，完整编码匹配后用空格上屏，原有 custom_phrase.txt 不改动。
- 候选外观：保留原配色或选择青绿、海蓝、石墨、松林、薄荷、雾蓝、深海、暖砂、纸白共 9 套配色，每套都有浅色和深色版本。原生卡片同时展示两种颜色，选择只更新预览，“保存并应用”后生效。可搜索本机已安装字体，设置候选字体、字号、横竖排列、间距，以及拼音显示在行内或候选窗；编号和注释跟随所选候选字体。预览与 Rime 配置共用颜色数据，布局仍是示意，实际渲染由鼠须管负责。“保留当前”恢复首次保存前的原配色，因未读取原配色，其预览仅展示布局。
- 输入与 AI：分别控制“本地接词联想”和“Kev 候选建议”，并设置 Kev 调用快捷键、应用默认中文/英文。Kev 仍按明确快捷键调用。
- 本地接词联想实验版：首次关闭，显示 3 个候选，最多接词一轮。仅在“雾凇拼音 · 接词实验”方案中生效，原雾凇拼音保留为回退入口。数字键、Tab 或点击可选择带“联想”标记的接词；字母开始新的拼音；Escape 或第一次退格退出联想，第二次退格正常删除；空格退出并输入普通空格，连续空格不选择接词，标点照常输入。控制台可调整 1–5 个候选，开关与数量即时生效。本地词库查询不请求或等待 Kev，当前 AI 开关和模型服务保持原状态。
- 每次保存前自动备份控制台状态及所涉及的配置，支持手动备份与恢复。恢复只处理控制台管理的设置、Kev 快捷键和本地联想开关/数量，保留其他配置及之后的无关编辑。恢复前也自动备份。并发窗口或外部编辑造成版本变化时拒绝旧版本保存。

配置保存在 `~/.keytrack/console`。常用语编译到 `~/Library/Rime/lua/keytrack_phrases_data.lua`，外观与翻译器放在自定义 YAML 中有明确标记的管理段。原有直接配色选择迁入管理段，原值保存在设置和修改前备份里，其余原配置保留。

桌面应用通过私有标准输入/输出管道调用 `console-native`，请求顺序处理，不监听任何网络端口。请求有大小和参数校验，保存仍有版本检查、备份和回滚。本地联想在 Rime 内查询接词库；Kev 候选建议只访问已有本机 Kev 服务。统计和短语不上传。可选浏览器版单独启用时，使用随机回环端口与访问凭据，修改操作还会校验请求来源。

## 字体搜索与拼音显示补充（2026-10-03）

原生外观页使用 AppKit 读取本机字体列表，按字体名称、显示名称和家族名称搜索。每个结果用该字体展示名称与样例，候选预览也使用所选字体。支持“保留原字体”“系统默认”“自选字体”；原有回退字体列表继续保留，未安装的名称会提示，预览使用列表中其余可用字体或系统字体。这里的“未找到”是原生预览的字体解析结果，鼠须管对字体别名与字符缺字的最终回退以真实候选窗为准。

拼音位置有“保留原设置”“行内”“候选窗”。新控件首次保留原值，不因为升级重置用户字体或拼音位置。“行内”预览将拼音放在模拟应用输入行；真正的行内拼音由正在输入的应用绘制，应用可能使用自己的字体。字体和位置选择只更新预览，保存后沿用现有备份、版本检查和重新部署流程。

鼠须管配色可以在全局 `style` 之后覆盖字体和拼音位置。显式选择时同时设置全局与选中配色的浅/深两套字段，避免配色盖掉选择；系统默认写入空字体名称，编号和注释默认跟随。新增值只写控制台受管段；原来同路径的直接标量设置迁入该段，并保存原行及注释。原有嵌套 `style`、配色定义和其他配置不改写。选择保留或恢复备份时，撤回新覆盖并恢复迁入前的原值。重复保存保持原备份值，旧设置文件和旧客户端缺少新增字段时不会重置已经保存的新选择。

已有标量使用普通字符串或布尔值时可安全接管；遇到数组、锚点、标签或多行标量则拒绝保存。保留原配色时，如果原 `style` 使用无法识别的行内映射或别名，不能确认实际选中的配色，也拒绝新增字体或拼音覆盖。受管段之外出现同路径的后续直接编辑时也拒绝覆盖，即使已经刷新了版本；应先在文件中解决冲突。无关的后续配置与注释继续保留。
