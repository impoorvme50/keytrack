# 公共接词质量第二轮

2026-10-03。本轮完成通用严筛、公开候选生成、复现、DB 构建及统一评分。**严格版未被选为正式公共候选升级**：它在旧冻结集和独立追加集中均损失整体 Top 3 与短语收益。全部产物、原生成器和历史记录归档在 `data/prediction/quality-v2/`；不据评分再调严筛规则，不替换 starter、fixture、默认数据库或本机正在使用的库。后续择定的是另立的保守精修版本，见 [保守精修记录](public-prediction-refinement-v3.md)。

## 评分前固定的通用规则

只使用既有固定公开训练文件，原始文件和分词依赖留在忽略目录。来源及许可仍见 [公共词库来源](public-prediction-data.md)，没有个人输入历史、常用语或新模型数据。

| 项目 | 固定值 |
| --- | --- |
| 数据仓库版本 | `5bd582fa28cd7143f2f9c852e08e23089d677c44` |
| 压缩训练文件 SHA-256 | `2162e0ed923fba62329cabf7e1493fbe59248afc94a62508e4abdea61e624627` |
| 抽样 | 种子 `20261002`；按原始顺序逐对话 1/32 随机抽样 |
| 分词 | jieba 0.42.1 原词典；`HMM=False`；词性读取同一词典第三列 |
| 单字／多字 token 原词典频次 | 至少 10,000／100 |
| 每对次数／不同对话／不同完整语句 | 至少 8／5／3 |
| 占完整键观测位置的比例 | 至少 3% |
| 前键／后词上限 | 3 前词、12 字／3 后词、8 字 |
| 每键保留 | 最多 8 项；仍只评分前 3 项 |

最终规则均在首次质量评分之前写明、实现并按派生样本审查。没有按照旧冻结集逐题添加候选，也没有读取追加留出集或改变接受集。

- 完整上屏文本精确查键，不增加运行时分词、截尾查键或归一化。标点、英文、数字、纯汉字数词、未知词、低词频 token 是硬边界，不跨语句或对话轮次。
- 单词键可在合法段内提取；由多个 token 组成的短语键须从硬边界分隔段开头提取。拒绝助词、语气词、感叹词或量词起头，以及机械重复词的前键；保留动词／形容词的 A 不 A、A 没 A 结构。
- 后词允许 1–3 个连续 token，以实义词或已有常见完整词结束。单字助词、介词、连词、量词、副词、否定词及词典 `g` 结尾语素标签不独立展示，但可以参与更完整的连续补全。
- 词性标签不是语法真值。两字以上、原词典频次至少 10,000 的既有完整词保留通道，避免粗标签误删常见表达；人名类标签仅保留两字以上、词典频次至少 1,000 的已有词，这不代表身份识别。
- 对话组去重之外，相同完整公开语句只能为词对增加一次不同语句支持，防止复制长句在不同对话中制造可靠性。交付不保存原句，只保留派生词对与统计。
- 多词补全与短补全共享实际分词前缀，并保留至少 70% 的次数与不同对话支持时，删除嵌套短项，避免同一表达占据多个候选。其余按次数降序、文字升序稳定排序。
- 拒绝已有不适宜内容、暴力和事故排除项；分词后的独立暴力动作词触发整语句排除。复合词不因包含某个单字就自动拒绝。

词对权重是次数除以该完整前键合法观测位置数的百万分整数。多词补全的事件会重叠，权重总和不解释为概率。统计在 builder 之前完成；人工 starter 仍拥有原 224 个完整键，整键覆盖语料，人工权重不与统计相加。

初稿原先预计 5,000–10,000 个语料键、20,000–50,000 条词对。评分前的固定编辑抽查发现，复制长句、词典粗标签和段中截取仍生成片段，于是加入不同语句支持、段首组合键、语素尾和暴力动作排除。所有修正均发生在任何质量评分之前。实际规模更小，不为满足数量目标放宽阈值；低频、口语和段中上屏短语的覆盖损失是真实代价。

## 复现与验收边界

```sh
.venv/bin/python data/prediction/quality-v2/generate-public-prediction.py \
  --input .local/prediction-corpus/lccc_base_train.jsonl.gz \
  --sha256 2162e0ed923fba62329cabf7e1493fbe59248afc94a62508e4abdea61e624627 \
  --source-url https://huggingface.co/datasets/silver/lccc/resolve/5bd582fa28cd7143f2f9c852e08e23089d677c44/lccc_base_train.jsonl.gz \
  --revision 5bd582fa28cd7143f2f9c852e08e23089d677c44 \
  --jieba-path .local/prediction-corpus/tools/jieba-0.42.1 \
  --min-count 8 --min-dialogues 5 --min-utterances 3 --min-share-percent 3 \
  --starter data/prediction/starter.ngram.tsv \
  --output /absolute/path/repro-output
.venv/bin/python scripts/build-predict-db.py --offline \
  --input data/prediction/quality-v2/public.ngram.tsv \
  --output /absolute/path/repro-predict.db --license MIT
```

16 项生成规则／产物测试通过；含已有安装、builder 与评测在内的 52 项 prediction 回归通过。starter、fixture、默认 DB 与冻结 v1 集哈希保持原值。相同受控引擎环境的 DB 可复现不代表跨引擎 ABI 或架构可通用。

此文档不把旧版引擎计时套用到第二轮，也不宣称本机已切库、真实菜单或点击验收通过。默认资源保持原库；严筛版的 DB 及清单只用于归档复现，不套用后续保守版性能结果。

## 独立追加集与最终选择

统一主验证的独立 v2 追加集共 100 条，其中 40 条完整短语。旧公共库与严筛版分别为：命中 28/100 → 24/100；整体 Top 3 6/100 → 5/100；命中内 Top 3 6/28=21.43% → 5/24=20.83%；短语 Top 3 1/40 → 0/40。因而严筛版虽相对小型 starter 通过初始门槛，对已扩充公共版本的优化没有成立。

后续保守精修在独立 v2 集和新冻结 v3 集的整体 Top 3 分别保持 6/100 与 4/100，均与旧公共库持平。旧 v1 集改善不能据此宣称新样例的泛化质量提高；两份独立追加集和本机真实候选窗的证据仍须分别陈述。

当前 `scripts/generate-public-prediction.py` 默认输出改为实验目录 `data/prediction/quality-v2/`，避免重跑严筛时覆盖正式候选。上面的归档生成器是测量时原字节快照；复现时显式指定 starter 和输出目录。
