## 严格下一词粒度

`acceptable_next` 只列出能直接跟在完整上屏单位后的一个完整词。名词、动词、形容词、时间词、功能词和独立语气词都可作为下一词；多词串或整句后文不可作为一个答案。多个答案只表示多个自然接续方向，不承诺枚举所有可能说法。

评分沿用 schema version 1 的字段及完整上屏文本精确查键口径，使用评测器的源表预处理与排序。不得清理空白或标点、截取后缀、重新分词查键、放宽为子串命中，或仅凭句意相近判为通过。Top 1 和整体 Top 3 的分母包含全部 100 条；边界另报不出候选率；未匹配探针按实际查键结果统计。
