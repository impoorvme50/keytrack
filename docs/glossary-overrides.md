# 候选释义工作术语与用户修订

2026-10-03 的扩充在原 120 个入门词上增加独立编写的 72 条工作术语，总计 192 条。原词表和来源清单保持原字节；新包按样品、交付、模具、外贸、质检、包装售后分类，清单位于 `data/annotations/work-terms-v1.manifest.json`。两包均未读取实际输入、评测数据或外部辞典。释义只是短提示，未作专业辞典或语言专家审校。

控制台中的显式修订保存到 `~/.keytrack/console/glossary-overrides.json`，与公共词表分开。修订可以覆盖标准词或添加新词，最多 300 条。删除一条修订后，该标准词重新使用附带的译法；新增词则退出覆盖层。保存及恢复沿用控制台的备份与版本复核，不从输入历史自动生成释义。

每条修订只接收 `word`、`en`、`ja`、可选 `reading`。中文词须为 1–8 个汉字，英文、日文都必填，读音可空；后三项各不超过 80 个字符，禁止换行、控制字符、首尾空白和重复中文词。词库按完整候选精确查询，保持原注释、AI／联想标记、候选排序与上屏规则。超长显示仍限制到 24 个 Unicode 字符，组合注释超过 64 字时优先保留原注释。

覆盖层在保存或重装输入法扩展时编译进用户的 `lua/keytrack_glossary.lua`，不增加按键中的文件读取、网络、模型请求或进程启动。公共打包输出始终仅含 192 条附带词，不读取私人覆盖层，也不把它复制回源码。

脚本只接受当前公共编译字节、当前覆盖层的精确编译字节，以及明确登记的 0.4.4 发布词表 SHA。修改覆盖层时，用已保存的旧覆盖层校验当前脚本，再编译新覆盖层；类似的管理注释或随意追加内容不构成覆盖许可。用户自行编辑的脚本会拒绝覆盖。

释义关闭时，修改覆盖层只重编译已经安装的受管词表，不安装可选模块或修改过滤器。尚未安装时只保存修订，首次显式开启时编译。单纯关闭释义仍可保留后来独立修改的脚本。恢复备份时使用当前词表和脚本版本重新编译恢复的覆盖层，不降级代码；备份缺失覆盖层时按空列表处理。

相关自动回归使用公开词和自造修订，覆盖合并优先级、重复及非法词条、300 条上限、冻结来源校验、注释预算、旧版字节迁移、独立脚本保护、关闭期间修改、重装保留与诊断一致性。实际候选窗、点击以及不同应用表现仍需单独验证，自动回归不替代真实菜单验收。
