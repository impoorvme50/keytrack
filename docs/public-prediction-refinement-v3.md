# 公共接词保守精修规则

2026-10-03。规则在任何新候选评分之前固定。严筛版在旧集和独立追加集中均损失覆盖、整体 Top 3 与短语收益，保留在 `data/prediction/quality-v2/` 作为可复现实验，不能作为正式候选升级。

本轮重新从 `quality-v1/public.ngram.tsv` 的完整派生词对表开始，不重分词语料、不收紧频次或支持、不要求短语从段首开始、不合并后词、不广泛删除功能词。已有完整键查询、候选粒度、权重顺序和稳定生成契约保留。

保守删除仅包含四项：

1. 纯汉字数词候选，如由零、一、二、十、百、千等数词字组成的文本；不按包含数字字形删除复合词。
2. 原词典明确标为 `g` 结尾语素的单字候选；不把其他标签扩展为功能词黑名单。
3. 相邻相同 token，或 A 助词 A 形式造成的异常重复完整前键；保留词典已有完整叠词和常规动词／形容词 A 不 A、A 没 A，不把“你说你”一类普通重复代词一概删除。
4. 分词后含独立暴力动作 token 的前键或候选；复合词不因包含某个单字就自动排除。

词典与分词依赖仍使用固定 jieba 0.42.1 原词典，`HMM=False`，词典 SHA-256 `7197c3211ddd98962b036cdf40324d1ea2bfaa12bd028e68faa70111a88e12a8`。这些删除只影响旧公共表，人工 starter 以整键最高优先完整保留。

原创工作／日常完整短语补充由独立作者编写，不读取冻结题目或公共候选内容来添加答案。合并优先级固定为 **starter > 原创补充 > 旧语料**：一个完整键的候选全部来自胜出的单一来源，各类权重不相加。新补充不得改写最高优先的 starter 键。

产物清单将记录原 v1 表、原来源链、词典、生成器、starter 和原创补充的来源与哈希；明确列出每种删除原因、删除完整键／词对数量、补充覆盖原键数量、增加新键／词对数量、最终与原公共库差异。评分后不再按分数调整规则或补充内容。

输出为独立候选目录，主验证通过后才选择正式候选；本机默认 DB、starter、fixture 和所有冻结评测集保持不变。

## 有限编辑审查

逐一检查固定 120 个旧来源键的最终 Top 3，共 **272 对**；再检查全部 60 个原创补充键的全部候选，共 **180 对**，合计 **452 对**。审查不交叉读取新评测题目或答案，评分后也不对源数据作针对性改动。

旧来源样本仍发现词序／机械疑虑，如 `你想你→想／好想你`、`呢我→呢`、`的和→你／我`；另有弱搭配与需要编辑注意的语境。新补充没有发现明确机械片段，但 `这批产品→已经／需要／预计` 仍需后续实义内容，作为弱候选单列，不判作错误。

全表核查先前 3 个已知片段：`方→二八`、`是的是→的` 已不存在；**`吧来→吧` 仍存在**，它不在此次 120 个旧键抽样中，不能把样本结果写成全部机械问题已清除。具体记录在 `quality-v3/public-review-findings.json`。这些是有限编辑关注项，不是全库错误率、质量正确答案或新的验收指标。

## 复现

```sh
.venv/bin/python scripts/refine-public-prediction.py \
  --jieba-path .local/prediction-corpus/tools/jieba-0.42.1 \
  --supplement data/prediction/workday-supplement-v1.ngram.tsv \
  --supplement-provenance data/prediction/workday-supplement-v1.manifest.json \
  --output /absolute/path/refinement-repro
.venv/bin/python scripts/build-predict-db.py --offline \
  --input data/prediction/quality-v3/public.ngram.tsv \
  --output /absolute/path/refinement-repro.db --license MIT
```

默认 v1 输入、来源清单、词典哈希和整键优先级由脚本固定；输出默认是独立 `quality-v3/` 候选目录。canonical 复制、报告路径更新和最终发布由统一主验证完成，不能用严筛版重跑覆盖该候选。
