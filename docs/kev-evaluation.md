## 数据与测量边界

两份原创公开样例各 60 条，日常／工作各 30 条；完整词 24、整句 18、歧义 12、拒绝 6。不读取真实输入、采集记录、聊天、客户材料或用户词典。全部输入文本与目标在模型请求前固定，MIT 许可与 SHA-256 由清单验证。

“未发生误提升”来自全部弃权，不能说明模型已准确。原始选择只作问题诊断，没有应用到输入法。它会选择部分短前缀，完整答案评测会把这些计为未完成；这也不是对用户后续分段输入成功率的测量。实际采用策略的结果始终与原序相同。

这里的弃权指保持候选原序，现有弱 AI 标记与用户手动选择仍可能出现；本轮未测用户手动采纳后的最终输入结果。

完整词原首项为 19/24，整句 17/18，歧义 12/12。公共池中没有“交期”和“发票已经开具”的完整答案，五选一无法补出不存在的词。前者可交给工作术语维护流程，后者需要候选解码／全码覆盖的独立检查；这组评测不直接补词或训练。

## 复现与离线测试

普通执行没有隐式联网，必须选择 `--live` 或 `--decisions`。只在现有服务已运行时执行真实评测；服务没开会失败返回，不会帮它启动。控制台只输出进度和结果分类，不打印请求、响应正文或服务器异常内容；派生报告仅记录样例 ID、决策、统计与耗时。

```sh
.venv/bin/python -m unittest tests.test_kev_eval tests.test_kev_rime -q
.venv/bin/python scripts/evaluate-kev.py --live \
  --dataset data/kev-evaluation/evaluation-v2.json \
  --json .local/msime-round1/kev-public-native-v2.report.json \
  --markdown .local/msime-round1/kev-public-native-v2.report.md
```

离线文件是一个 JSON 对象，把每个冻结样例 ID 映射到 `{"index": 2, "probability": 0.93, "margin": 0.86}` 或 `{"error": "timeout"}`。必须覆盖冻结 ID 且不能增加额外 ID；失败类别只允许 `timeout`、`connection`、`invalid_response`，避免把异常正文作为内容日志。`--decisions FILE.json` 输出会明确标为注入决策，不会误称实测。

如需重新采集当前公共 Rime 候选，使用新输出文件；不能覆盖本轮冻结文件：

```sh
.venv/bin/python data/kev-evaluation/capture_public_rime.py \
  --output data/kev-evaluation/public-rime-recapture.json
```

## 指标定义与后续采用条件

Top 1 用完整字符串精确匹配多个可接受答案，拒绝样例不进完整答案分母；目标不在池内仍计入整体分母，另报告池内子集。强决策仅在概率 ≥0.90 且领先 ≥0.30 时采用，两个边界都包含等号。低于边界称弃权；超时或无效响应称失败，保留原首项。强选原首项属于采用但没有提升。无变化包括弃权、失败及仍选首项。

救回是原首项不正确、采用后完整答案正确；弄坏是原首项正确、采用后不正确。误提升包括从正确变错和从错变另一错误，并包含拒绝样例中的提升。其率分母是实际提升数，零提升时率为 null，不能写成“0% 误提升”；原正确首项回退率另用原正确首项数作分母。

19 项新测试覆盖哈希冻结、分母、救回／弄坏／误提升、歧义、完整答案与前缀、零分母、概率及 margin 边界、非法分布、失败安全回退、URL 拒绝、显式 live 与耗时分组；与原 bridge 11 项测试合计 30 项通过。原桥接与输入法服务本轮保持原样。

独立再采集的公共 Rime 候选与 v2 冻结文件逐字节一致，SHA-256 同为 `00442da1bf3b86c9537324a5bfea3f0ac08f7a477b277e81e7cdb6bd01cbe4ee`。这次复验不请求模型。

本轮是小型便利样例，概率也仅是未校准的模型分数。建议继续保留现有策略；增加独立未见场景、公共 Rime 日常过滤器的隔离快照和真实候选窗验证，尤其补齐全码候选覆盖信息，再比较模型或提示设计。阈值校准需要独立验证／盲测及误提升约束，不能按这 60 条追改。此处中文五候选收益评测独立于提交后的接词评测，不能用接词 Top 3 替代。
